# 《个人投资知识库 Web App》V1.0 产品需求文档

> **给开发 AI 的说明：请严格按照以下需求开发。**
>
> 这是一个个人投资知识管理网站，不是股票行情软件，也不是交易软件。
>
> 第一版本的目标是：
> **帮助用户记录和整理投资知识、研究过的股票/公司、基金以及个人投资笔记。**
>
> 请优先保证页面简洁、结构清晰、数据可以长期保存和编辑。
>
> **不要擅自增加实时行情、AI助手、新闻、股票搜索、自动推荐、自动交易等功能。**

---

# 1. 产品定位

项目名称暂定：

**My Investment Knowledge Base**

中文名称：

**我的投资知识库**

核心理念：

> **记录 → 学习 → 研究 → 思考 → 沉淀**

这个网站不是用来替代：

* 同花顺
* 东方财富
* 支付宝
* 券商交易软件

这些软件负责：

> 行情、交易、实时数据。

本网站负责：

> **我的投资知识和思考。**

# 6. 知识详情

例如：

## PE｜市盈率

```text
分类：估值

一句话解释：

公司市值相当于一年净利润的多少倍。

────────────────

详细解释

PE = 市值 ÷ 净利润

PE常用于比较公司估值。

但是PE不能单独判断股票贵不贵，
需要结合公司增长速度、行业、
盈利质量和历史估值进行分析。

────────────────

我的理解

PE本质上是在回答：

“市场愿意为公司现在一年的利润
支付多少钱？”

────────────────

相关知识

PB
ROE
PEG
净利润
估值
```

# 11. 公司投资逻辑

这是公司页面最重要的内容之一。

字段：

### 为什么研究这家公司？

例如：

```text
因为公司处于高端装备行业，
拥有大型压缩机和核主泵等业务，
想研究它的行业壁垒。
```

### 我的投资逻辑

例如：

```text
1. 行业需求持续增长
2. 公司订单持续增加
3. 毛利率改善
4. 新业务形成收入
```

### 主要风险

例如：

```text
1. 订单增长放缓
2. 毛利率下降
3. 应收账款增加
4. 估值过高
```

### 后续观察

例如：

```text
□ 下一季度营收
□ 净利润
□ 毛利率
□ 在手订单
□ 经营现金流
```

这些内容全部允许用户自由编辑。

# 24. 给开发AI的最终指令

**请先根据以上产品需求开发 V1.0。**

开发原则：

1. **不要增加需求文档中没有的功能。**
2. **不要制作实时行情系统。**
3. **不要制作AI聊天助手。**
4. **不要制作股票推荐功能。**
5. **不要制作交易功能。**
6. 优先保证数据库、增删改查和页面交互稳定。
7. 代码结构清晰，方便后续继续扩展。
8. 所有核心数据必须持久化保存。
9. UI优先考虑PC桌面端。
10. 如果某个功能存在多种实现方式，优先选择**最简单、可靠、方便后续扩展**的方案。

**完成V1.0后，不要自行继续开发V2.0功能，先停下来等待下一步需求。**

---

### 我建议你就先把这份给开发 AI

而且**不要一次告诉它“以后还要做什么”**。先让它把这个 V1.0 跑起来。

等第一版真正能用以后，我们再做 **V1.1**，我会建议只加三个东西：

**① 知识关联图
② 财务数据图表
③ 投资复盘**

这三个加进去以后，你这个东西才会开始从“个人笔记网站”逐渐变成真正的**投资知识系统**。
